# GeoPandas


Entry point for GeoPandas-aware schemas and models. Requires the ``geopandas``
extra. Implementations live in `pandera.api.geopandas`; this top-level module
re-exports the public API.

`pandera.geopandas` re-exports the full `pandera.pandas` namespace in addition
to the GeoPandas-specific classes below.


- [`GeoDataFrameModel`](./generated/pandera.geopandas.GeoDataFrameModel.html)
- [`GeoDataFrameSchema`](./generated/pandera.geopandas.GeoDataFrameSchema.html)
